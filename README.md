# homebrew-tap

Official Homebrew tap for Gaurav Wankhede developer tools and autonomous agent utilities.

## Installation

Add this tap to your Homebrew installation:

```bash
brew tap Gaurav-Wankhede/tap
```

## Available Formulae

### WebFind
Self-hosted native search engine for AI agents — pure CLI, zero cost.

```bash
brew install webfind
```

Run web search:
```bash
webfind search --live "Rust 2024 edition"
```
